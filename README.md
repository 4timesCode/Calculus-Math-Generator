# Calculus-Math-Generator
This program generates a calculus problems for the user to solve. The problems can range from differentiation, integration, and evaluating stationary points.


# Libraries used
To use this application, the following libraries are required:
- mathgenerator
- tkinter
- matplotlib

# Running the application
To run the application, you have to build a virtual environment that has the libraries mentioned above installed. Depending on your IDE, starting a virtual environment will be different.

Once you have the virtual environment configured and running, run:
python3 app.py
